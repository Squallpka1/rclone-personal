Rclone Personal

Rclone Personal is a private, single-user desktop configuration of rclone. It synchronizes selected Google Drive files with the account owner's own computer.

This is not a public file-sharing service. Only the owner authorizes access to their Google account. This website contains no Drive files, credentials, or sign-in form.

Google Drive access is used to read, download, upload, update, rename, and delete files as needed for two-way synchronization.
