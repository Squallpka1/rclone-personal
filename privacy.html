Privacy policy

Rclone Personal is a single-user configuration of rclone for synchronizing selected files between the owner's computer and the owner's Google Drive. It is not offered as a service to other users.

Google data access and use

The configuration requests Google Drive permission to list, read, download, create, update, rename, and delete files for two-way synchronization. Although Google grants account-wide Drive access, the synchronization configuration targets a selected workspace folder.

Storage and sharing

File transfers take place between the owner's computer and Google Drive. Local file copies, synchronization state, logs, and backup copies may be retained for synchronization, troubleshooting, and recovery. OAuth credentials are stored locally on the owner's computer. They are not included in this public website or repository.

This configuration has no separate application server. It does not sell Google user data, use it for advertising or AI training, or intentionally send it to third-party analytics services. Google Drive's existing sharing settings remain controlled by the owner.

Control and deletion

The owner can stop synchronization and revoke access through their Google Account's third-party connections settings. Revoking access does not automatically delete existing local files, logs, or backups; the owner can remove those separately. File deletions can propagate between the computer and Google Drive while synchronization is enabled.

This website

These are static informational pages with no sign-in form, application cookies, analytics scripts, or access to Google Drive. GitHub Pages hosts the public website and may process visitor information under GitHub's privacy statement.
